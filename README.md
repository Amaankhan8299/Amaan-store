# Amaan Store

A modern E-Commerce web application built using React, Redux Toolkit, and Vite. This project provides a fast and responsive shopping experience with product listings, cart management, and a clean user interface.

## Features

* Product Listing
* Product Details Page
* Shopping Cart
* Redux State Management
* Responsive Design
* Fast Development with Vite
* Modern React Components

## Technologies Used

* React.js
* Redux Toolkit
* JavaScript (ES6+)
* Vite
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/Amaankhan8299/Amaan-store.git
```

Navigate to the project directory:

```bash
cd Amaan-store
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
